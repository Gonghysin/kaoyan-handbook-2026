## 更换 PDF

1. 打开仓库的 `pdf/` 目录，删除旧 PDF，上传新 PDF（`pdf/` 里只能有 **1 个** PDF，文件名随意，下载时用这个文件名）。
2. 提交后 GitHub Actions 会自动把 PDF 渲染成网页图片并重新部署，约 1–2 分钟生效。
3. 进度在仓库的 **Actions** 页查看，失败会显示红叉。

网页上的标题取自 PDF 的「标题」属性（WPS：文件 → 属性），没有时用文件名。

浏览量统计使用不蒜子（busuanzi），显示本页累计浏览次数。
